Ceci est un logiciel 💻 de gestion de deux stocks différents. Elle peut nous aider à bien gérer les entrées et sorties des articles/produits, à des rapports éventuels de l'année, d'un mois où d'une seule journée, elle peut également nous fournir des rapports financiers notamment notamment les pertes et benefices ainsi que les statistiques.

Pour lancer cette application, il faut d'abord importer le fichier sql qui se trouve dans le répertoire "/database file", dans un SGDB MySQL et votre ordinateur doit avoir le JAVA runtime donc il faut installer le jdk correspondant. Après tout, tu peux choisir lancer ce fichier exe intutile "Stock Manager" ou bien le fichier bat intitulé "gstock" ou bien le fichier JAR se trouvant dans "/dist" intitulé "stock", mais le meilleur reste le fichier EXE car vous pourrez le creer un raccourci et le déplacer au bureau.
